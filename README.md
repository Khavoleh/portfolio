## Local Development

If you wish to run this portfolio locally, follow these steps:

### Prerequisites
* Node.js
* pnpm package manager

### Installation
1.  **Clone the repository:**
```bash
git clone https://github.com/Khavoleh/portfolio.git
cd portfolio
```
2.  **Install dependencies:**
```bash
pnpm install
```

### Running Locally
Start the development server:
```bash
pnpm dev
```
